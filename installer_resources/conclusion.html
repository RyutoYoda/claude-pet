インストール完了

/Applications/Claude Pet.app にインストールされました。

初回起動時に依存ライブラリを自動インストールするため、インターネット接続が必要です（数秒かかります）。

⚠️ 起動方法: このアプリは Dock に表示されません。
必ずターミナルから以下のコマンドで起動してください： 

open /Applications/Claude\ Pet.app

Claude Code と連携するには

~/.claude/settings.json の hooks セクションに以下を追加: 

{
  "hooks": {
    "Stop": [{"matcher": "", "hooks": [{"type": "command",
      "command": "python3 '/Applications/Claude Pet.app/Contents/Resources/notify_hook.py'"}]}],
    "Notification": [{"matcher": "", "hooks": [{"type": "command",
      "command": "python3 '/Applications/Claude Pet.app/Contents/Resources/notify_hook.py'"}]}]
  }
}
